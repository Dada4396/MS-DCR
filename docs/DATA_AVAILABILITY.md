# Data Availability Notes

The demo mzML files in this repository are small subsets extracted from the authors' original DDA and DIA mzML files. They are intended for smoke tests and do not replace the full benchmark data set.

Recommended manuscript wording:

> Source code, documentation, benchmark utilities and demo mzML files for MS-DCR are available at `https://github.com/Dada4396/MS-DCR`. Versioned releases are archived through Zenodo. Public benchmark data sets are available from PRIDE under accession numbers PXD071367, PXD068828, PXD066688 and PXD065993. The remaining in-house data sets are available from the corresponding author upon reasonable request, subject to institutional data-sharing restrictions.

Large raw mzML files should not be uploaded directly as journal supplementary files unless the journal explicitly permits files of that size.
